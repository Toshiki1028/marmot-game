# ふれあいまーもっと

2匹のマーモットが1本のにんじんを奪い合う、2D固定視点の対戦アクションゲームです。

かわいらしい動物たちによる、パンチ・回避・咆哮を駆使した駆け引きが楽しめます。

## ゲームの特徴

- にんじんを過半数食べた側が勝利
- パンチや回避による攻防
- 睡眠・座り食いによるリスクとリターン
- 咆哮と相殺による心理戦
- 3ステージ連戦のCPUモード
- 2人対戦モード

## 開発環境

- HTML
- CSS
- JavaScript
- Figma
- Visual Studio Code

## 操作方法

| 操作 | 1P |
|---|---|
| 左パンチ | 左クリック |
| 右パンチ | 右クリック |
| 左回避 | ホイール上 |
| 右回避 | ホイール下 |
| 座り | ホイールクリック |
| 咆哮 | 左右クリック連続入力 |
