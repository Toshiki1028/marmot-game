**バージョン：** 1.0（開発途中版）
**更新日：** 2026年11月12日
**開発環境：** HTML / CSS / JavaScript
**画面設計：** Figma（1920×1080基準）

# 1. ゲーム概要

## 1.1 コンセプト

『ふれあいまーもっと』は、2匹のマーモットが1本のにんじんを奪い合う、2D固定視点の対戦アクションゲーム。

かわいらしい動物の見た目に反して、パンチ・回避・睡眠・咆哮などの駆け引きを重視した対戦を楽しめる。

## 1.2 基本ルール

- マーモット2匹が1本のにんじんを争奪する。
- にんじんを取得したマーモットは自動的に食事を開始する。
- 食事量が全体の50%を超えた側が勝利する。
- 相手に攻撃を当て、にんじんを落とさせることができる。
- スタミナと咆哮ゲージを管理しながら戦う。
- キャラクター間の前後移動はなく、固定位置で戦う。

## 1.3 ゲームモード

**CPU戦**
- 3ステージ連戦方式。
- STAGE 1 → STAGE 2 → FINAL STAGE。
- CPUはステージが進むほど強くなる。
- 途中で敗北したらタイトル画面へ戻る。
- 3連勝で総合スコアをランキングへ登録できる。

**2P対戦**
- 1Pはマウス、2Pはキーボードで操作する。
- 基本的な戦闘ルールはCPU戦と共通。
- 対戦終了後の遷移・スコア処理は未確定。

## 1.4 ランキング

- ブラウザのローカルストレージに保存する。
- CPU戦3連勝時の総合スコアで順位を決定する。
- スコア計算式は未確定。

画面遷移は以下のとおり。

1. タイトル画面
2. 操作説明画面（CPU戦・2P戦）
3. 3カウント演出
4. 対戦画面
5. 勝敗演出
6. 勝利時は次ステージへ、敗北時はタイトルへ

カウントダウンでは、3で自分のマーモット、2で相手、1で全体を映す演出を使用する。

# 3. キャラクターと操作

## 3.1 配置

- 画面右側：1P（背面視点）
- 画面左側：CPUまたは2P（正面視点）
- 中央：にんじん

## 3.2 1P操作

| 入力 | アクション |
|---|---|
| 左クリック | 左パンチ |
| 右クリック | 右パンチ |
| ホイール上 | 左回避 |
| ホイール下 | 右回避 |
| ホイールクリック | 座り開始・座り解除 |
| 左右クリック連続入力 | 咆哮 |

咆哮は左→右、右→左のどちらでも発動できる。

## 3.3 2P操作

| 入力 | アクション |
|---|---|
| F | 左パンチ |
| D | 右パンチ |
| J | 左回避 |
| K | 右回避 |
| G | 座り |
| D・Fの組み合わせ | 咆哮 |

2Pの咆哮も、旧仕様の長押しではなく、連続入力方式に変更する予定。

# 4. キャラクターの行動状態

キャラクターは次の状態を持つ。

| 状態 | 内容 |
|---|---|
| 通常 | 攻撃・回避・睡眠が可能 |
| パンチ | 攻撃モーション実行中 |
| 回避 | 回避モーション実行中 |
| 通常食事 | にんじん所持中 |
| 座り食い | 食事速度2倍 |
| 睡眠 | スタミナ・咆哮ゲージ急速回復 |
| 立ち上がり | 座り解除中の無防備状態 |
| 咆哮 | 特殊アクション実行中 |
| 疲労 | スタミナ0による行動不能 |
| 相殺硬直 | 咆哮を相殺された際の行動不能 |

状態によって、使用可能なアクションが異なる。

---

# 5. パンチシステム

## 5.1 モーション

パンチは3段階で構成する。

| 段階 | 時間 | 内容 |
|---|---|---|
| 振り出し | 180ms | 攻撃開始・残像 |
| パンチ到達 | 100ms | 攻撃判定 |
| 引き戻し | 170ms | 残像・硬直 |

合計450ms。

## 5.2 攻撃ルール

- パンチ1回につきスタミナを1消費する。
- にんじん未所持時のみパンチ可能。
- パンチ中は通常の別アクションを実行できない。
- 振り出し中に反対側のパンチ入力が成立すると、咆哮へ移行できる。
- 引き戻し中は新たなパンチを開始できない。
- 咆哮は例外的に優先発動できる。

## 5.3 被弾

- パンチを受けた側はスタミナを1失う。
- 被弾時にHITマークと短い振動演出を表示する。
- にんじん所持中に3回被弾するとドロップする。
- ドロップ時点で3ヒットカウントをリセットする。

---

# 6. 回避システム

## 6.1 モーション

| 段階 | 時間 | 内容 |
|---|---|---|
| 回避開始 | 80ms | 回避判定あり |
| 回避姿勢 | 140ms | 回避判定あり |
| 戻り動作 | 180ms | 回避判定なし |

合計400ms。

## 6.2 回避ルール

- 回避のスタミナ消費は0。
- 回避開始から220msまで回避判定が有効。
- 戻り動作中は無防備。
- 相手のパンチ方向と対応する方向へ回避した場合のみ成功。
- 回避成功時に咆哮ゲージを5%回復する。
- 回避中の追加回避・通常攻撃は不可。
- 自然回復は回避中も継続する。

---

# 7. スタミナシステム

## 7.1 基本数値

| 項目 | 数値 |
|---|---|
| 最大スタミナ | 10 |
| 初期スタミナ | 10 |
| パンチ | -1 |
| 被弾 | -1 |
| 回避 | 0 |
| 自然回復 | 2秒で+1 |
| 睡眠回復 | 1秒で+2 |
| 疲労時間 | 4秒 |
| 疲労後の復帰値 | 3 |

## 7.2 自然回復

- 通常の待機中に自然回復する。
- 食事中・座り食い中も自然回復する。
- 回避中も自然回復する。
- パンチ・咆哮中は回復を停止する。
- 自然回復のカウントは、短い入力のたびに最初からやり直さない。

## 7.3 スタミナ0

スタミナが0になると疲労状態へ移行する。

- 4秒間行動不能。
- 攻撃・回避・睡眠・座り食い・にんじん取得不可。
- 食事進行停止。
- 自然回復停止。
- 4秒経過後、スタミナ3で復帰。
- にんじんを所持している場合は保持を継続する。
- 咆哮のみゲージが100%なら使用可能。
- 咆哮を使用しても疲労時間は短縮されない。

---

# 8. 睡眠システム

## 8.1 発動条件

- にんじん未所持。
- スタミナが1以上。
- 通常状態で座り入力を行う。

## 8.2 効果

- スタミナが毎秒2回復する。
- 咆哮ゲージが急速回復する。
- 攻撃・回避不可。
- 睡眠中は相手から2回被弾しても睡眠を維持する。
- 3回目の被弾で強制的に立ち上がる。

※ 3ヒット耐性は被弾を無効化するものではない。

## 8.3 解除

睡眠中にゲーム操作を入力すると立ち上がりモーションへ移行する。

- 解除入力ではパンチ・回避を実行しない。
- 立ち上がり時間は250ms。
- 立ち上がり中は無防備。
- 復帰後に通常操作を受け付ける。
- 咆哮のみ例外として、立ち上がり硬直を無視して発動できる。

---

# 9. にんじんシステム

## 9.1 所持状態

にんじんは以下のいずれかの状態になる。

- 地面
- 1P所持
- CPUまたは2P所持

同時に複数のキャラクターが所持することはない。

## 9.2 取得

- 地面のにんじんを拾うモーションで取得する。
- 拾い動作中は攻撃・回避不可。
- 拾い動作中に被弾すると取得を中断する。
- 拾い中は無敵にならない。
- 同時に拾おうとした場合は競り合いに移行する。

取得モーションの具体的な時間は要調整。

## 9.3 食事

- にんじん取得後は自動で通常食事を開始する。
- 所持中は攻撃不可。
- 回避・咆哮・座り食いが可能。
- 食事は時間経過で進行。
- 食事中に回避すると食事を一時停止する。
- 回避終了後、自動的に食事を再開する。
- 自分の累計食事量が全体の50%を超えたら勝利。

## 9.4 座り食い

- にんじん所持中の座り入力で開始。
- 食事速度が通常の2倍になる。
- 座り食い中は攻撃・回避不可。
- 操作入力で立ち上がりを開始する。
- 立ち上がり中は食事を停止する。
- 完了後は通常食事へ戻る。
- 咆哮のみ例外的に直接発動できる。

## 9.5 にんじんドロップ

ドロップ条件は以下。

1. 所持中にパンチを累計3回受ける。
2. 所持中に相手の咆哮を受ける。

通常パンチによるドロップの場合：

- にんじんを地面に落とす。
- 被弾側に1.5秒のパンチ無敵を付与する。
- ドロップした本人は0.8秒間再取得できない。
- 相手は即座に取得可能。
- 3ヒットカウントをリセットする。

咆哮によるドロップの場合：

- 即座ににんじんを落とす。
- 1.5秒のパンチ無敵は発生しない。
- 咆哮による4秒間の行動不能へ移行する。
- ドロップした本人には0.8秒の再取得禁止を適用する。
- 咆哮は通常の3ヒットカウントには含めない。

## 9.6 無敵時間

- 通常の3ヒットドロップ時は1.5秒間パンチ無敵。
- 無敵中のパンチはスタミナを減らさない。
- 咆哮はパンチ無敵を貫通する。
- 無敵中も通常の操作は可能。

# 10. 咆哮システム

## 10.1 発動条件

- 咆哮ゲージが100%。
- 左右のパンチ入力を180ms以内に連続入力。
- 入力順は左右どちらからでも可能。
- 旧仕様の同時長押しは廃止する。

咆哮は通常状態、食事中、睡眠中、座り食い中、疲労中など、原則としてどの状態でも使用可能。

## 10.2 ゲージ回復

| 条件 | 回復量 |
|---|---|
| 初期値 | 50% |
| 回避成功 | +5% |
| 睡眠中 | 1秒で+20% |
| 通常時の自然回復 | なし |
| 咆哮発動 | 0%へ |

最大値は100%。

## 10.3 咆哮の演出

1. 咆哮入力成立。
2. WARNINGマークを0.6秒間表示。
3. WARNINGが消えた瞬間に咆哮発動。
4. 咆哮を受けたマーモットが振動する。
5. 咆哮演出終了後、相手は4秒間行動不能。
6. 咆哮を使用した側は立ち姿勢へ戻る。

## 10.4 咆哮命中時の効果

- 相手のスタミナを0にする。
- にんじんを持っている場合は即ドロップ。
- 食事進行を停止する。
- 咆哮中は相手を振動させる。
- 咆哮演出終了後、4秒間行動不能にする。
- 行動不能中はにんじんを拾えない。
- 4秒後、スタミナ3で復帰する。

## 10.5 咆哮の相殺

WARNING表示中に、相手が座り動作を開始すると相殺できる。

判定は座り完了時ではなく、**座り開始の残像モーションが成立した瞬間**に行う。

### 相殺成功時

- 咆哮は不発。
- 咆哮ゲージは返還されない。
- 相殺成功側は立ち姿勢のまま即行動可能。
- 咆哮した側は2秒間硬直する。
- 相殺による追加のスタミナ消費はない。

### 相殺可能な状態

- 通常立ち姿勢
- 通常食事状態

### 相殺不可能な状態

- パンチ中
- 回避中
- 睡眠中
- 座り食い中
- 立ち上がり中
- 疲労中
- その他の行動不能状態

咆哮による相殺と、咆哮を自分で発動する処理は別々に判定する。

# 11. にんじん競り合い

双方がほぼ同時ににんじんを拾おうとすると発生する。

- 制限時間は3秒。
- 左右交互の連続入力で競う。
- 成功入力回数が多い側の勝利。
- GOOD・MISS表示で入力結果を知らせる。
- 競り合い中は専用BGMに切り替える。
- 同点の場合はにんじんを地面に残し、通常戦闘へ戻る。

競り合いの入力受付間隔や細かな成功条件は要調整。

# 12. CPUシステム

CPUは3段階の強さを持つ。

| ステージ | CPUの強さ |
|---|---|
| STAGE 1 | 弱 |
| STAGE 2 | 中 |
| FINAL STAGE | 強 |

ステージが進むにつれ、攻撃頻度・回避精度・咆哮の使用判断などを変化させる。

見た目の装飾もステージごとに変更する。

具体的なCPU行動ロジック・数値は未確定。

# 13. モーションと残像

## 13.1 基本方針

各アクションは、基本姿勢から目的の姿勢に移行する途中と、戻る途中に残像を使用する。

残像は演出であると同時に、アクションの予備動作・硬直・入力可能時間を知らせる役割を持つ。

## 13.2 対象

- 左パンチ
- 右パンチ
- 左回避
- 右回避
- 座り
- 立ち上がり
- にんじん取得

咆哮は通常の残像演出とは異なり、WARNINGを予備動作の合図に使用する。

## 13.3 表示ルール

- 既存のマーモット画像の画風・毛並み・角度を維持する。
- モーションに応じて画像を差し替える。
- 背景透過PNGを使用する。
- キャラクターの位置・サイズが不自然に変わらないようにする。
- モーション開始・終了時刻はJavaScriptで管理する。

# 14. 判定の優先順位

同じタイミングで複数のイベントが発生した場合、次の原則を適用する。

1. 勝敗が確定した場合、以降の戦闘処理を停止する。
2. 食事による勝利と攻撃・咆哮が同時成立した場合は、食事の勝利を優先する。
3. 有効な咆哮入力は通常アクションより優先する。
4. WARNING中の座り開始による相殺は、実際に座りきる前に確定する。
5. パンチ無敵中は通常パンチの被弾を無効化するが、咆哮は有効とする。
6. にんじんの所有状態と行動状態は常に整合させる。
7. 古いモーションのタイマーが新しいアクションの画像や状態を上書きしないようにする。
